# Context Kit — かんたん初期設定

VS Codeのチャットに **@contextkit 初期設定** と入力すると、初期設定の入力欄が開きます。
通常のエージェントチャットへの文章だけで推測させず、拡張機能がこの合図を受け取って設定画面を開きます。

## 導入

1. GitHub Releasesの最新リリースから **contextkit.vsix** をダウンロードします。`Source code.zip` ではありません。
2. VS Codeの拡張機能画面で「…」→「VSIXからのインストール」を選び、このファイルを指定。
3. 作業用フォルダをVS Codeで開く。
4. チャットに **@contextkit 初期設定** と入力。
5. 目的を一言で入力し、既存のMarkdown設計書があれば選ぶ。
6. 作成・追記の内容を確認して「設定する」。MCP接続の信頼確認が出たら内容を確認する。

**拡張版は外部Node.jsのインストールやターミナル操作を不要にする構成です。**
VS Code 1.102以降のデスクトップ版と、利用可能なGitHub Copilotが前提です。
Marketplaceには未公開のVSIX配布版です。実際のVS Code上の動作は利用環境で確認してください。
ローカルフォルダ向けの初期版で、WSL・SSH・Dev Container・ブラウザー版は対応対象外です。

## 初期設定で行うこと

- 足りないMarkdownの棚・登録台帳・引き継ぎ用プロンプトだけを作る。
- 新しいプロジェクト概要に、入力した目的を「検討中」として記録する。
- 選んだ設計書をコピーせず、その場所を台帳へ登録する。
- 原文保存や引き継ぎメモの混入防止のため、`.gitignore` の末尾へ除外ルールを追記する場合がある。
- 拡張内蔵のMCP接続をVS Codeの公式APIで提供する。`.vscode/mcp.json` の手動編集は不要。

既存の資料・台帳・プロンプトは上書きしません。既存の台帳がある場合、その内容を継続利用します。
以前の手動設定の context-kit 接続がある場合は重複の警告を出します。自動削除せず、MCP一覧で旧接続を停止してください。
途中で取り消した場合、確認前にはファイルを作りません。設定が完了しても「AIが理解した」「接続確認済み」とは扱いません。

## 自動で圧縮される範囲

初期設定では `.github/copilot-instructions.md` に専用の指示を作成または追記します。
これにより、通常のCopilotがログ・JSON・テキスト・Markdownを読む際は、`kit_read`の`safe`モードを優先的に自動選択します。
既存の指示は上書きせず、同じ専用ブロックを重複して追加しません。

ツール選択はモデル判断と実行許可にも左右されるため、必ず自動実行される保証はありません。
重要な作業では、ツール実行欄で `kit_read` または `kit_context` が呼ばれたことを確認してください。

Copilotの会話履歴全体、別のツールで直接読んだ内容、ファイルへ保存されていないターミナル出力は自動圧縮できません。
会話が長くなった場合は `/context-handoff-save` でメモを作り、利用者が新しいチャットを開いて `/context-handoff-resume` で再開します。

## 「初期設定を保存していません」と表示された場合

初期設定を始める前に、設定対象の**フォルダをVS Codeで開いてください**。ファイルを1つ開いただけの状態では開始できません。
入力欄、設計書の選択、ファイル選択、最終確認のどこで中断したかはチャットに表示されます。
プロジェクト説明は空欄でも進められます。設計書がない場合は **「あとで記入する」** を選び、最後に **「設定する」** を選択してください。
チャットから入力欄が開かない場合は、表示された **「初期設定をもう一度開く」** ボタン、またはコマンドパレットの **「Context Kit: 初期設定を始める」** を実行してください。

## 初期設定後

- **@contextkit 状況**：登録資料と出力記録・再確認の要否
- **@contextkit 圧縮状況**：文字数・バイト数による圧縮状況
- コマンド一覧の **Context Kit: 用語集を開く／設計書を開く**：資料を編集する

この窓口は初期設定と状況確認の専用です。一般の相談や実装には通常のCopilotエージェントチャットを使います。
接続確認には通常のCopilotで「kit_contextで一覧を見せて」と依頼し、実際のツール呼び出しが成功したか確認してください。
接続や利用が制限されている場合、VS Codeの版、MCPの信頼・実行許可、組織のポリシーを確認します。

## 安全性と限界

拡張は設定済みの作業フォルダだけを対象にします。内蔵MCPは127.0.0.1の一時ポートで動き、プロセスごとのトークンが必要です。
外向きの公開サーバーやクラウドサービスは立てません。トークンは拡張の設定ファイルへ保存しません。
VS CodeやCopilotの認証情報を取得する処理はありません。
資料やログの秘密情報を完全自動で検出・削除する機能はありません。AIに渡す資料を確認してください。
用語集・設計書・引き継ぎメモは機密になり得ます。Gitの除外は暗号化やクラウド同期停止ではありません。
この統計はCopilot全体のトークン数・請求額・要約品質を測定するものではありません。

停止するときは **Context Kit: このフォルダで停止する**。資料ファイルは消しません。
