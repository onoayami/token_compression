## 0.5.6

- 認証後などに「指定ポートで別のHeadroomが稼働しています」と表示され、自動圧縮を開始できない問題を修正しました。VS Codeの再読み込みや拡張の更新で以前のContext Kitが起動したHeadroomが残っていた場合、それを確認したうえで引き継ぎ（再起動）ます。Context Kit以外のプロセスは引き続き終了しません。
- 「自動圧縮を停止」は、以前のContext Kitが残したHeadroomも停止します。ウィンドウを閉じたときは、他のウィンドウが使っているHeadroomを止めません。
- 認証の案内を手順付きにし、「コードをコピーしてGitHubを開く」ボタン1つでコードのコピーと認証ページの表示を行うようにしました。

## 0.5.5

- Headroom認証（GitHubとの連携）が途中で止まった場合に「Headroomは別の処理中です」と表示され、やり直せない問題を修正しました。
- 「Headroomを認証」をもう一度実行すると、未完了の認証を中止して新しいデバイスコードで最初からやり直します。自動圧縮の稼働中でも認証し直せます。
- 認証は15分で自動的に打ち切り、失敗・期限切れ時の通知とチャットに「Headroomを認証し直す」ボタンを表示します。チャットでは `@contextkit /auth` でもやり直せます。
- 認証成功後は自動圧縮を再起動し、新しい認証を反映します。

## 0.4.0

- インストール用ファイルは **contextkit.vsix** です。Source codeのZIPではありません。
- VS Code → 拡張機能 → … → VSIXからのインストール。
- 作業フォルダを開いて、チャットに **@contextkit 初期設定** と入力します。
- 拡張版は外部Node.js不要の構成です。VS Code 1.102以降のローカル・デスクトップ環境向けです。
- 既存ファイルを上書きせず、変更確認後に初期設定します。
- 自動テストと公式vsceによるパッケージ作成を行いますが、VS Code実機・Windows/macOSのGUI動作や組織ポリシー下での利用は未検証です。
