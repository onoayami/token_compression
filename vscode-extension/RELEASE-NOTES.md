## 0.5.0

- macOSのVisual Studio Code安定版で、利用者が明示同意した場合だけ外部Headroom `0.41.0`を管理venvへ導入し、Copilot送信前の自動圧縮を開始できます。
- device flow認証、allowlist環境、ビーコン・統計保存抑止、health検証、所有PIDだけの停止、累積再起動上限、設定の`unwrap`復元を追加しました。
- Headroomの圧縮はログ・JSON・反復ツール出力向けで、意味要約や密な自然文の縮小を保証しません。

## 0.4.2

- 初期設定時にCopilot用の指示を作成・追記し、対応するログ・JSON・テキスト・Markdownでは `kit_read` を自動的に優先するようにしました。
- 既存の `.github/copilot-instructions.md` は上書きせず、Context Kit専用ブロックを一度だけ追記します。
- Copilotの会話履歴そのものは自動圧縮できないため、長い会話は引き継ぎメモと新しいチャットで整理します。

## 0.4.0

- インストール用ファイルは **contextkit.vsix** です。Source codeのZIPではありません。
- VS Code → 拡張機能 → … → VSIXからのインストール。
- 作業フォルダを開いて、チャットに **@contextkit 初期設定** と入力します。
- 拡張版は外部Node.js不要の構成です。VS Code 1.102以降のローカル・デスクトップ環境向けです。
- 既存ファイルを上書きせず、変更確認後に初期設定します。
- 自動テストと公式vsceによるパッケージ作成を行いますが、VS Code実機・Windows/macOSのGUI動作や組織ポリシー下での利用は未検証です。
