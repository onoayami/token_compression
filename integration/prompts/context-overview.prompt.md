context-kit の kit_context を action=list で使い、共通知識の棚を確認してください。
本文を全部読み込む依頼ではありません。必要な場合だけ次のページの一覧を取得します。

- 資料の名前、正式／検討中／過去版、版、適用範囲、場所を示す。
- 登録のみ、原文の場所のみ出力、本文の一部／全体の出力記録、要再確認を区別する。
- 変更検知のためのローカルなハッシュ確認は、本文をAIへ渡したことと同じではない。
- 出力記録があっても、AIが受け取り・理解し・正しさを確認した保証ではない。
- 正式という状態は利用者の宣言であり、出典の真実性や最新性の保証ではない。
- 内容・台帳の版や適用範囲が変わった場合、原文保存版の期限切れ、取得失敗は未確認として示す。
- 今回の作業に必要な資料だけ、kit_context action=read と id を指定して読む案を出す。
- この依頼だけで資料本文を全件読んだり、正式化したり、コードを変更したりしない。
